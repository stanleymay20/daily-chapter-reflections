# Daily Scripture Companion

Build a private, non-commercial app named “7-Chapter Bible Study”. Purpose: a personal daily Bible reading app whose Scripture text is fetched from the official YouVersion Platform API, never generated by AI.

MVP requirements:
1. Mobile-first React/TypeScript + Tailwind + shadcn UI. Calm, reverent reading experience, excellent on iPhone.
2. Home screen shows today’s date in Europe/Berlin and the seven scheduled chapters. Seed 17 Aug 2026 with: Genesis 42, Nehemiah 3, Psalm 79, Proverbs 25, Zephaniah 2, Luke 7, 1 Corinthians 14. Put schedule data behind a clean local data module so a 365-day plan can be imported later.
3. Each chapter card opens a dedicated Reader view. The reader fetches the ACTUAL Bible text from YouVersion Platform using a server-side backend function. Do not fabricate or bundle Bible text.
4. YouVersion API base URL: https://api.youversion.com/v1. Authentication header: X-YVP-App-Key. Read the key ONLY from a server-side secret/environment variable named YVP_APP_KEY. Never expose it to browser code, logs, source maps, client env vars, or Git.
5. Implement server endpoint/function that can:
   - GET /bibles (or equivalent backend action) to list Bible versions available to this app key
   - fetch a complete passage/chapter using the passage API, e.g. /bibles/{version_id}/passages/{passage_id}
   - optionally use chapter/verse endpoints when needed
   - validate version_id and USFM passage identifiers; enforce timeouts and graceful handling for 401/404/429/5xx.
6. Default to an available English translation discovered from /bibles. Prefer BSB id 3034 if available. Do NOT assume NIV access; if NIV id 111 is returned by /bibles, let the user select it. Show required copyright/attribution returned by the API for the selected Bible.
7. USFM mapping needed for today: GEN, NEH, PSA, PRO, ZEP, LUK, 1CO. Chapter passage IDs should be like GEN.42, NEH.3 etc.
8. UI states: missing server secret (“Connect YouVersion App Key in project secrets”), loading, success, unavailable translation, API error, and retry. Never fall back to AI-generated Bible text.
9. Add reading progress for the seven chapters using localStorage initially: Not started / Reading / Complete, plus daily completion count.
10. Add optional Study Notes below the Scripture, stored locally. Keep commentary separate and collapsed by default. Scripture must visually remain the primary content.
11. Add a small “Source: YouVersion Platform” indicator and selected translation name. Do not claim personal YouVersion account sync yet.
12. No ads, subscriptions, payments, paywalls, commercial language, or public launch features.
13. Add a README or setup documentation explaining exactly how to add YVP_APP_KEY securely in Lovable project secrets, how the backend protects it, and how to test Genesis 42. Do not include any real key.
14. Add basic tests for schedule lookup, USFM mapping, and API error normalization.

Important security rule: if YVP_APP_KEY is absent, the app must show the setup state and never make a direct browser request to YouVersion.

Build the functional MVP now. Do not add YouVersion OAuth/sign-in yet; that comes later after we have our own deployed callback URL.
